# Sidhi Gym Tracker

Daily gym log for SIDHIMUSIC / Ashu.

Repo: https://github.com/SIDHIMUSIC/sidhi-gym-tracker

Live after GitHub Pages is on:
https://sidhimusic.github.io/sidhi-gym-tracker/

## Pages on kaise karein

1. Repo Settings > Pages
2. Source: Deploy from a branch
3. Branch: `main` / folder `/` (root)
4. Save

## Use

Pehli baar apna alag ID + password set karo.
Public signup nahi hai. Data usi browser me rehta hai.
Phone change se pehle Export JSON lo.

Routine steps:
1. Bhajan + jaati walk
2. Workout / weights
3. Ulta / cooldown
4. Beech ka circuit
5. Aadhe ghante baad walk
6. Treadmill se pehle
7. Treadmill
8. Treadmill ke baad body weight
